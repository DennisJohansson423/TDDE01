# Lab 1

## Lab focus
This lab covered K-nearest neighbours, linear and ridge regression and logistic regression with basis function expansion in R.

## What I learned
- How to train and evaluate supervised learning models for classification and regression
- How to use validation and test data to study model quality and generalization
- How hyperparameters and model complexity affect performance
- How regularization and basis expansion can improve model behaviour
- How to compare models using suitable error measures such as misclassification error, cross-entropy and MSE
